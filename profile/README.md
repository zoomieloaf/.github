# ZoomieLoaf

Small tools for reading and writing. Mostly loaf. Occasionally zoom.

- **[Margin](https://github.com/zoomieloaf/margin)**: Markdown, edited the way you read it.
  A VS Code extension that opens `.md` files as a clean page you edit in place.
  The file stays plain Markdown, so ticking a checkbox is a one-line diff.
  [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=zoomieloaf.margin) ·
  [Open VSX](https://open-vsx.org/extension/zoomieloaf/margin)
